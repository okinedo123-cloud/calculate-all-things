How Investment Return Is Calculated

Investment return measures how much an investment has gained or lost compared with the amount originally invested.

Total Return Formula

Total Return (%) = (Final Value − Initial Investment) ÷ Initial Investment × 100

Annualized Return

Annualized return estimates the average compounded rate of return per year over the investment period.

Annualized Return = (Final Value ÷ Initial Investment)1 / Years − 1

Example

If an investment grows from $10,000 to $15,000, the investment has gained $5,000. The total return is 50%. If that growth occurred over five years, the annualized return is lower than 50% because the return is spread across the entire five-year period.

Understanding Investment Returns

Investment returns can be positive or negative. A positive return means the ending value is greater than the initial investment, while a negative return represents a loss.

Important Limitations

This simple calculator does not account for additional deposits, withdrawals, dividends taken as cash, taxes, investment fees, inflation, or the timing of cash flows. Those factors can affect actual investment performance.
